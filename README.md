# eShop

A dynamic online shop built step by step to practise full-stack web development:
vanilla JavaScript first, then a PHP + MySQL back end, then a React front end.

**Stack:** HTML · CSS · JavaScript · PHP · MySQL · React (bonus)

## Current status
🟢 Milestone 1: Product card grid (vanilla JS)

See the full plan in [ROADMAP.md](ROADMAP.md).

## Run it locally
Stage 1 is plain HTML/CSS/JS, so no setup is needed:

1. Clone the repo
   ```bash
   git clone https://github.com/EllieK-coder/eshop.git
   cd eshop
   ```
2. Open `index.html` in your browser
   (or use the VS Code **Live Server** extension for auto-reload)

## Project structure
```
eshop/
├── index.html        # page layout
├── css/
│   └── style.css     # styles (CSS variables + grid)

│   ├── products.js   # product data (later replaced by a PHP API)

```
